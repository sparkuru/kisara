# Kisara is back

QQ bot with one shared message pipeline and switchable OneBot 11 (NapCatQQ) and Tencent official adapters. See [Running Kisara](docs/operations.md) for startup and deployment.

## Development

The [application development template](docs/application-template.md) maps the current architecture and the required steps for adding a feature. Feature usage, configuration, processing, and storage details live in the opening docstrings of the corresponding `src/kisara/application/services/` modules.
